App 操作方式

安裝與檢查

npm install
npm run doctor

完整 Docling 環境：

uv sync --python 3.12 --extra docling
uv run kb doctor

PDF 轉 Markdown

  1. 將 PDF 放入唯讀的 data/input/。
  2. 執行 npm run build:kb。
  3. 在 data/output/<document_id>/ 查看結果。

續跑與驗證

npm run kb -- resume <document_id>
npm run kb -- validate <document_id>
npm run kb -- index <document_id>
npm test
只有在使用者明確啟用 provider 後才執行 enrichment。遠端 provider 可能使圖片與文字離開本機，必須先確認資料授權與隱私要求。

已知限制

  • 目前只完成一份 86 頁高度影像化文件，尚未涵蓋密集表格、原生文字與 200+ 頁壓力基準。
  • Page profile 與品質規則仍需代表性資料校準。
  • PyMuPDF fallback 不提供 OCR。
  • Windows 非 UTF-8 console 輸出中文 QA 可能觸發 UnicodeEncodeError；可先設定 $env:PYTHONUTF8 = "1"。
  • 每個 OCR batch 都會初始化 converter，本次累計解析約 11 分 37 秒。
  • 技術代碼與精確 token 的 OCR 錯誤仍可能被標成 success。
  • 超過預設 100 頁的 PDF 會分成數個 Markdown 部分檔。
  • 技術數字不會自動視為已驗證事實。
  • 尚未建置向量資料庫、多模態檢索或人工審核 UI。
